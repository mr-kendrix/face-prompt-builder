# 🎭 Crooked Smile — Face Prompt Builder

A free, offline, single-file HTML app for building image-generation prompts of realistic, naturally asymmetrical faces.
17 categories, 6 languages, two roll modes, Krea-2 optimizer & offline reverse-engineer — and the prompt is always in English.

## 🇬🇧 English

Crooked Smile — Face Prompt Builder is a free, offline, single-file HTML app for crafting image-generation prompts (Stable Diffusion and modern image LLMs) of realistic, naturally asymmetrical faces. Choose from 17 finely tuned categories — archetype, hair, style & vibe, cosmetics, lighting, camera — or roll a random face with one click: the dice either re-rolls every category or only fills the empty ones while your chosen terms stay pinned. A built-in optimizer rewrites the tag list as a natural-language scene description for image LLMs such as Krea 2, and a reverse-engineer mode turns your own written description into a face using a local LLM (LM Studio, OpenAI-compatible API) — still fully offline. Save unlimited recipes, preview the head pose in 3D, and bypass any category with a single click. The interface is available in six languages, but the generated prompt is always output in English. Simply open the HTML file in any browser — no installation, no server, no internet required. All faces are fictional adults (18+); the app never depicts real people. Free for personal, hobby, and student use — not licensed for commercial use.

`face_prompt_builder_offline_v2.html` is the current version (V2); `face_prompt_builder_offline.html` is the previous V1 build. Both work the same way: open the file in any browser — no installation, no server, no internet.
